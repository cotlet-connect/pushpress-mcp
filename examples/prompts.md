# Example prompts for PushPress gym owners

- List members who have not booked in 14 days and draft a check-in message. Send nothing yet.
- List pending cancellations this month and draft a save message for each.
- List Friday class no-shows and late cancels with the fee each owes, so I can charge them.
- Work out coach pay from classes and appointments for this pay period.
- Build my own inactive-members endpoint with Custom API after I review the browser workflow.
